Update Log & Info

Latest Update: 11/8/2026

  • Netflix-Style Card Morph: Hovering a movie card now animates it into a wider panel showing the backdrop, title, description and quick actions — the card grows horizontally in place instead of a floating popup. Works on desktop and TV; mobile keeps tap-to-detail.
  • Continue Watching Management: Finished movies and fully-watched series auto-remove from Continue Watching. A "Clear All" button and per-card × buttons let you clean up manually. Home rails update live when you toggle favorite or watched — no more reloading to see changes.
  • Icon Reliability: Material Symbols icons now stay hidden until the font is confirmed loaded, so you never see "play_circle" as literal text. Falls back gracefully after 3 seconds if the font check stalls.
  • Refresh Metadata Button: A small reload icon in the detail modal and on the card morph panel clears the cached data for a title and re-fetches it from the API — handy when a title updated or loaded wrong.
  • 10-Minute Session Persistence: Reloading within 10 minutes of your last activity no longer asks for the password. The session survives hour boundaries too.
  • TV-Safe Dropdowns: All dropdowns are now custom multi-choice popups that can be closed with Escape or Back — no more soft-lock risk on TV. Arrow keys navigate, Enter selects.
  • Ad Shield Removed: The sandbox feature that blocked some sources from playing has been removed entirely — all embeds now load without sandbox restrictions.
  • Cleaner Poster Placeholder: Missing posters now show a plain dark gradient instead of an emoji and text.

Latest Update: 11/6/2026

  • Buttons Rewired The Old Way: Every card and button now uses the exact direct-click mechanism from the original version — no deferred pipelines, no double-fire, no lost clicks. Verified with real mouse clicks.
  • Password Always First: The login gate shows on every load, topmost layer, before anything else renders. Deep links wait for login.
  • 10-Minute Session: Idle re-prompt tuned to 10 minutes.
  • Zero-Animation Dialogs: All dialogs render instantly on every browser — entrance animations and backdrop blur removed (they caused invisible-dialog states on some devices).
  • Compatibility Sweep: Modern CSS shorthands replaced with universal equivalents — works on older device browsers too.
  • Hover Simplified: Back to the original scale-and-glow card hover — the expansion panel experiment is retired.
  • Search Results Grid: Fixed to a proper poster grid (was stacking vertically on some devices).
  • About Section: Creation date and version info added to this log.

  • Sidebar Navigation: Switch the header buttons to a TV-friendly left sidebar (Settings → General).
